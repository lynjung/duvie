# Duvie

Open this folder in VS Code. In its terminal, run:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser. No packages or build step required.

Today holds schedules and the eight original routines. Nook holds the otter and weekly check-in. Plan shows habit progress and shared milestones.

This is a local prototype. The profile selector simulates both partners in one browser. Records persist in that browser. There are no accounts, privacy controls, or cross-device sync. Treat the profile switcher as a demo and use sample data. Events use the browser's local timezone.
